[REPLACE ME.] An experiment write-up should be short — a few paragraphs, no
headings if you do not need them. What were you curious about, what was the
smallest thing you could build to find out, and what did it tell you?

It is fine for the answer to be "this did not work." A dead end you can explain
is worth more than a success you cannot.

```text
hypothesis → smallest possible test → result → what it changed
```

[REPLACE ME.] Close with the thing that surprised you.
